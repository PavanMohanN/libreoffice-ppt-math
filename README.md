# libreoffice-ppt-math

Type math in LibreOffice Impress and Writer just like PowerPoint's Math AutoCorrect (`\alpha` → `α`, `^2` → `²`, `^{n+1}` → `ⁿ⁺¹`, `->` → `→`). Powered by [Espanso](https://espanso.org)

## Install & Run (Linux)

1. Make sure **Espanso** and **Python 3** are installed on your computer[cite: 1, 3].
2. Open your terminal and run these commands one by one:

```bash
git clone git@github.com:PavanMohanN/libreoffice-ppt-math.git
cd libreoffice-ppt-math
bash install.sh
